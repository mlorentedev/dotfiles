## Decisions made during implementation

- **Two-PR split of CLI-027.** `dotf update` first (deploy-model-agnostic — it just re-runs setup,
  no secrets); `dotf sync` second (the higher-blast-radius secrets + repo→deployed deploy).
- **Bare-scheduler-env repo fallback.** `ResolvePath` returns "" when the contract is undiscoverable
  (minimal systemd `--user` / Task Scheduler env), which would silently stop self-deploy. Added
  `repoForUpdate()` = seam-primary + `$HOME/Projects/dotfiles` last-resort fallback, reproducing the
  shell twins' `${DOTFILES_REPO_DIR:-…}` exactly, so no `Environment=`/task-env wiring is needed.
- **Scheduler unit files stay floor** (AUDIT-007) — repointed to call `dotf` directly (no `.ps1`
  wrapper), not regenerated by a `dotf schedule` primitive.

Cheapest honest fix: treat it as a finding (`field-missing` with a detail that says no field is declared), which makes `dotf secrets drift` gate on `AGE_KEY_PERSONAL`'s undeclared bw target and forces the registry to either name a field or drop the block. Either soften the criterion to name the empty-value case as the deliberate exception (it is currently only in `verification.md`, so the contract and the code disagree), or report the empty value as present.

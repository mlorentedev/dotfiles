### Recommended next steps (before archive)

Minimum set to flip to PASS:

1. **Fix the Windows duplication (Blocker).** Add the equivalent strip-rule to `Convert-SkillRecord` in `setup-windows.ps1` (drop lines matching `^generated(_from|_sha)?:` while `fm -eq 1`, mirroring `scripts/compile-harness.sh`'s awk fix), and add a named regression test that actually deploys a record carrying pre-existing `generated_*` fields and counts occurrences in the rendered output — not a source-text grep. This PR is merged, so the fix needs its own follow-up (spec or ticket), not a rebase of this one.
2. **Resolve the `generated_from`/`generated_sha` referent mismatch (Major).** Either fix the code (record-relative `srcpath` at deploy time, both skill and agent call sites, plus updating the two bats tests that currently pin the vault-path literal) or fix the spec (correct AC2's and the proposal's wording to state the intentional design, if the repo owner decides the current behavior is acceptable). Either resolves the contradiction between what AC2 says and what ships.
3. Optional, not required for PASS: tighten the opencode/copilot assertions in the AC2 bats test (Minor finding) for symmetry with the claude block.

Given the PR is already merged, item 1 in particular should be filed as its own ticket/spec rather than reopening #927 — the fix is now cross-platform-safety work on `main`, not a change to a pending PR.

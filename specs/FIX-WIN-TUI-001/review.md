### Verdict

FAIL

Rubric path: one C in every dimension but Scope, no D → PASS WITH GAPS minimum. Severity path escalates it: three **REAL** Majors (redaction guarantee voided and unrecorded; `features.json` declaring "not implemented"; cleanup destroying pre-existing environment state) each require a fix and a re-review. Two of the three sit outside the contract set, but the `features.json` finding is inside it, so this review is **stale the moment that file is fixed** — a re-review round is the mechanism, not an inconvenience.

### Recommended next steps

- **Code (outside the contract set, can be fixed without re-staling this review):** make the `finally` save-then-restore (`$null`-aware) rather than delete; wrap the decode in `try/catch` and reject a non-base64 or short-key payload loudly instead of launching with a partial environment. Add named regression tests — a pwsh/Pester case in `tests/powershell-profile.bats` that drives the wrapper against a stub `dotf` (the synthetic pattern validated in this review) and asserts the launch happened and a pre-existing value survived.
- **Vault / recorded decision (not a contract-set edit):** either implement ConPTY behind `interactiveChildSupported()` for Windows, or record the Windows exception to ADR-028 in a lesson and amend the ADR. The Base64 bypass restores behaviour by voiding the redaction property, which lesson 270 rejects in terms; an unrecorded trade-off is the part that is actually wrong.
- **Contract set (fix, then re-review):** give `features.json` a real feature whose `verification` command passes, with `state` and `evidence` filled. Nothing above should be applied to `proposal.md` / `tasks.md` before that decision is taken, because the archive gate measures freshness against exactly these three files.
- **`verification.md` (excluded from the staleness check — disposition each item here):** add the `## Promotion candidates` section; `dotf spec archive`'s third pre-flight refuses a `verification.md` without it and no flag skips it (`cli/internal/spec/promotion.go:51`). Replace the AC1/AC3 narrative with the exact commands and outputs from a Windows host, or state plainly that they are Windows-only and cannot be evidenced from CI with the test that would cover them.
- **Do not archive yet**: `dotf spec archive FIX-WIN-TUI-001` would be refused on the missing promotion section alone, and the three REAL Majors above are open.

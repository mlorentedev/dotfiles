### Recommended next steps
- **Code + tests (`cli/internal/harness/pushguard.go`, `cli/internal/harness/pushguard_test.go`)**:
  - In `splitStringOption` / `skipOptions`, recognize bundled short options containing `S` (`-iS`, `-vS`, etc.) and `C` (`-iC`, etc.) on `env`; track known value-taking wrapper options (such as `-C`, `-u`, `-a`, `-g`, `-h`, `-p`, `-r`, `-t`, `-U`) so their argument is consumed even when its basename matches a name in `wrapped` (like `git` or `bash`); and apply `if envDir { saved := g.dirKnown; g.dirKnown = false; ... }` around `g.splitScript(script, depth)` in `simple`.
  - In `shellString` for `ShellPowerShell`, mark `dirKnown = false` (via a local copy of `g` with `dirKnown = false`) when `-WorkingDirectory` / `-wd` (or any unambiguous `-w...` prefix) is present before running `g.nested`.
- **Code + tests (`cli/internal/harness/pushguard_lex.go`, `cli/internal/harness/pushguard_test.go`)**:
  - Strip or skip PowerShell `<# ... #>` block comments in `ShellPowerShell` mode (or avoid treating `<#` as a redirection in `stripRedirects` / `lexer` so the command following `#>` is preserved).
  - In `stripHeredocs`, skip `<<` when preceded by an unquoted odd run of `\` (`\<<EOF`), and allow optional quotes around the shell name in `shellFeeder` (`"bash" <<EOF`, `cat <<EOF | "bash"`).
  - Add regression rows for all reproduced cases in `cli/internal/harness/pushguard_test.go`.
- **Spec (`verification.md`, `features.json`) + re-review**: Refresh the test evidence SHA in `verification.md` and `features.json` after fixing and run a fresh adversarial review round.
